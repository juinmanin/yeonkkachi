About the Project

Yeonkkachi (연까치, Korean for magpie) is an autonomous AI trading research project that combines market analysis, risk management, and social-media transparency into a single open-source system. Every trade decision is logged and announced publicly, making the project fully auditable.

Mission Statement

"To advance ethical, transparent, and auditable AI in financial markets — empowering researchers and the public to understand, critique, and improve autonomous decision-making systems."
  • 🔍 Radical transparency – every trade is logged and tweeted in real time.
  • 🛡️ Risk-first design – hard limits on position size and drawdown.
  • 🧪 Research-grade – paper-trading mode by default; live trading requires deliberate opt-in.
  • 🌐 Open source – all code is public under an open licence.

Features

🤖

AI Signal Generation

Pluggable strategy modules evaluate technical indicators and generate BUY / SELL / HOLD signals.

⚖️

Risk Management

Configurable max position size and drawdown limits are enforced before every trade.

🐦

Twitter Transparency

Every trade is announced via the Twitter / X API so the public can follow along in real time.

📊

Trade Logging

Structured JSON-lines trade log makes it easy to analyse performance and audit decisions.

Public Transparency

All trades are published to our Twitter/X feed the moment they occur. You can also browse the full trade history in data/ on GitHub.
