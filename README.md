# 🐦 Yeonkkachi – Ethical AI Trading Research

> **DISCLAIMER: This project is for research and educational purposes only.
> Nothing here constitutes financial advice. Trading involves significant risk of loss.**

Yeonkkachi (연까치, Korean for *magpie*) is an open-source, fully transparent autonomous AI
trading research project. Every trade decision is logged, published to Twitter / X, and
committed to this repository so that anyone can audit the strategy at any time.

---

## Mission Statement

> "To advance ethical, transparent, and auditable AI in financial markets — empowering
> researchers and the public to understand, critique, and improve autonomous decision-making
> systems."

- 🔍 **Radical transparency** – every trade is logged and announced publicly in real time.
- 🛡️ **Risk-first design** – hard limits on position size and drawdown are enforced before every trade.
- 🧪 **Research-grade** – paper-trading mode by default; live trading requires deliberate opt-in.
- 🌐 **Open source** – all code is public.

## Setup Instructions

### Prerequisites

- Python 3.10+
- A Twitter / X Developer account with a project app (for live tweet posting)

### 1. Clone the repository

```bash
git clone https://github.com/juinmanin/yeonkkachi.git
cd yeonkkachi
```

### 2. Create and activate a virtual environment

```bash
python -m venv .venv
# Linux / macOS
source .venv/bin/activate
# Windows
.venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Configure environment variables

Copy the example and fill in your credentials:

```bash
cp .env.example .env   # (or create .env manually)
```

Required variables:

| Variable                     | Description                        |
|------------------------------|------------------------------------|
| `TWITTER_API_KEY`            | Twitter / X API key                |
| `TWITTER_API_SECRET`         | Twitter / X API secret             |
| `TWITTER_ACCESS_TOKEN`       | OAuth access token                 |
| `TWITTER_ACCESS_TOKEN_SECRET`| OAuth access token secret          |
| `TWITTER_BEARER_TOKEN`       | Bearer token (read-only API v2)    |
| `MAX_POSITION_SIZE_USD`      | Max trade size in USD (default 100)|
| `MAX_DRAWDOWN_PCT`           | Max allowed drawdown % (default 5) |

> ⚠️ **Never commit your `.env` file.** It is listed in `.gitignore`.

### 5. Run the bot

**Paper-trading mode (single cycle, no Twitter posting):**

```bash
python -m bot.main --once
```

**Continuous mode (tweets every cycle):**

```bash
python -m bot.main --interval 60
```
